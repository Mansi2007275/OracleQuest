**OracleQuest** is a decentralized, AI-debated prediction market platform built for the ultra-high-throughput **Somnia Network** (Chain ID: `50312`). By pairing multi-agent AI research (Bull vs. Bear sentiment analysis via Google Gemini) with on-chain EVM smart contracts, OracleQuest enables users to discover prediction events, stake native STT tokens on binary outcomes (YES/NO), track real-time probabilities, earn XP/ranks, and claim proportional pool rewards upon verification.

---

## 🌟 Key Features

* **🤖 Multi-Agent AI Debate Engine**: Powered by Google Gemini. Every market features continuous thesis debate generated by specialized **Bull**, **Bear**, and **Risk Assessment** AI agents, supplemented by live CoinGecko & NewsAPI market data feeds.
* **⚡ Somnia High-Throughput EVM Contract**: Custom `EventContract.sol` engineered to handle rapid prediction placement, automated probability ratio calculations, non-reentrant reward claims, and admin/oracle event settlement.
* **🎮 Web3 Gamification & Leveling**: Gamified user progression with XP tracking, dynamic ranks (*Beginner*, *Analyst*, *Oracle*), daily quests, and milestone achievement badges.
* **🔮 Interactive AI Oracle Assistant**: Integrated real-time AI Chatbot (`/api/oracle-chat`) allowing users to ask questions, explore statistical odds, and analyze market sentiment before staking.
* **📱 Cyberpunk Dark Glassmorphism UI**: Built with Next.js Turbopack, Tailwind CSS, Framer Motion animations, and Shadcn UI components optimized for desktop and mobile devices.

## 🚀 Quick Start Guide

### 1. Prerequisites
Ensure you have Node.js (v18+ recommended) and npm/pnpm installed on your system.

### 2. Installation
Clone the repository and install project dependencies:
```bash
git clone https://github.com/your-repo/oraclequest.git
cd oraclequest
npm install
```

### 3. Environment Setup
Copy `.env.local.example` to `.env.local`:
```bash
cp .env.local.example .env.local
```

Ensure `.env.local` contains valid API keys for your setup:
```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# Google Gemini AI Key
GEMINI_API_KEY=your-gemini-api-key

# Somnia Network & Contract Address
NEXT_PUBLIC_SOMNIA_RPC_URL=https://dream-rpc.somnia.network
NEXT_PUBLIC_CHAIN_ID=50312
NEXT_PUBLIC_CONTRACT_ADDRESS=0x742d35Cc6634C0532925a3b844Bc454e4438f44e
PRIVATE_KEY=your-deployer-private-key

# Market Data Feeds
COINGECKO_API_KEY=your-coingecko-key
NEWS_API_KEY=your-newsapi-key
```

### 4. Running the Development Server
Start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to interact with OracleQuest.
